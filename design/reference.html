CAPE DLS Light

The platform's own design language. A cool near-white ground, a violet accent, Inter throughout with no serif anywhere, and large diffuse shadows tinted toward the accent rather than toward black.

This is a style reference, not a page to copy. Match the tokens, spacing and component shapes below. Do not reuse this page's wording, sections or layout. Your application has its own content and structure.
One value here differs from the platform's current CSS. --text-faint measured 2.66:1 against this background, well below WCAG AA for placeholder text. It is marked contrast-fixed in the palette. Use the value on this page.

Every neutral is tinted toward indigo. There is no true grey and no true black, which is most of what keeps this from reading as a generic dashboard. Each status colour ships with its own -bg and -ink partner, so a chip never needs a hand-picked pair at the call site.

Atmosphere

The hero gradient

A single diagonal wash used behind headline surfaces. It is part of the identity, not decoration.

--hero-gradient: linear-gradient(160deg, #EEEDFD 0%, #DCE4FF 45%, #D8F0EC 100%);
--blob-a: #A8C1FF;   --blob-b: #5B54F5;   --blob-c: #FF955A;

The blob tokens are the drifting background accents. Keep them low-opacity and slow; they should never compete with content.

Type

Inter is the only typeface. There is no serif in this design language. Both --font-body and --font-display resolve to Inter; hierarchy comes from weight and size alone. This reference makes no network requests, so it falls back to your system UI font. In the application, load Inter and declare it first in both variables.

Using this reference
  • Lift the custom properties from :root verbatim, including the contrast-fixed value.
  • Use the v2 names (--bg, --text, --border). The older --paper/--ink/--hairline names exist only as aliases.
  • Inter only. No serif anywhere. Hierarchy is weight and size, with tight tracking on display sizes.
  • Every neutral is indigo-tinted. No true greys, no true black.
  • Pair each status colour with its own -bg and -ink token rather than choosing your own.
  • Shadows are large, diffuse and accent-tinted, never neutral.
  • Code panels stay dark in both themes.
  • If your application offers a dark mode, pair this with CAPE DLS Dark rather than inventing one.
